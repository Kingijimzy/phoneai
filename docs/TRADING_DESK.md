# Orion Trading Desk

Permissioned trader **workspace** — not settings-only.

## Open it

Home → **Trading** opens `TradingDeskActivity`:

| Tab | What you get |
|-----|----------------|
| **Desk** | Live pulse, quotes, scan / match, shortcuts |
| **Chat** | Coach chat in-desk (same memory as Trading Coach agent) |
| **Playbook** | Accept / reject candidates, enable rules, match |
| **Controls** | Packs status, keys/limits, Agent Control, full coach |

Settings (keys, watch service, CSV) stay on `TradingActivity` via **Settings** / Controls.

## Alive feedback

- Pulse card: mode, packs, session, playbook counts, watch quotes (refresh ~45s)
- Chat chips: scan, BTC bias, session, risk
- Scanner + playbook match with result dialogs

## Safety

- Research default on; execution opt-in
- No silent orders — confirm each time
- Testnet first

## Agent tools

Still available in main Orion chat via `TradingToolHandlers` when packs allow.
